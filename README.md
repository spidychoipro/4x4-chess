# 4x4 체스 — 작지만 날카롭게

구글 플레이의 [4x4 체스](https://play.google.com/store/apps/details?id=com.westplain.chess)를 보고 만들었다. 같은 아이디어를 웹으로 옮기되, 리뷰에서 자주 보이던 불편함을 고치는 게 목표였다. 광고도, 로그인도, 추적도 없다.

## 무엇이 다른가

- **운빨 없음.** 도전 코스 10단계는 전부 검증된 위치다. 각 스테이지는 정답 첫 수가 유일하고, 그 수부터 강제 체크메이트가 나온다는 걸 프로그램으로 확인한다. 이길 수 없는 판이나 무작위 배치가 없다.
- **규칙을 제대로 지킴.** 폰의 두 칸 전진, **앙파상**, 4종 승격(두 칸 전진 승격 포함), 체크·체크메이트·스테일메이트, 기물 부족·50수·동일 위치 3회 무승부를 지원한다. 판이 작아 캐슬링만 제외했다.
- **레이팅별 봇 8단계.** 미니맥스 + 알파베타 + 퀴에스센스 엔진에 탐색 깊이, 평가 정교함, 실수 확률을 다르게 줬다. 100점(첫 걸음)부터 2800점(최정상급)까지 골라 붙을 수 있다. 처음 두어본 사람도 이길 수 있고, 최정상급 봇은 한 수만 어긋나도 끝난다. 도전 모드 상대도 랜덤이 아니라 실제로 수를 계산한다.

  | 레이팅 | 이름 | 성격 |
  | --- | --- | --- |
  | 100 | 첫 걸음 | 규칙을 막 배운 사람처럼 가끔 엉뚱한 수 |
  | 300 | 동네 형 | 기물은 잘 잡지만 함정은 잘 못 봄 |
  | 600 | 취미 생활 | 한 수 뒤까지 봄, 실수도 종종 |
  | 1000 | 동아리 | 기물과 위치를 함께 봄 |
  | 1500 | 클럽 챔피언 | 눈앞의 실수를 저지르지 않음 |
  | 2000 | 국가대표 | 두 수 뒤까지 계산 |
  | 2400 | 그랜드마스터 | 세 수 뒤까지 읽음 |
  | 2800 | 최정상급 | 가장 긴 계산, 한 수만 어긋나도 끝남 |

  이 레이팅은 실제 FIDE 공식 점수가 아니라 이 웹 게임 안에서의 체감 난이도 구분이다.
- **되돌리기와 힌트.** 퍼즐에서 막히면 힌트를 볼 수 있다. 힌트를 쓰면 별이 하나 줄어든다.
- **광고·추적·다운로드 없음.** 정적 사이트라 브라우저에서 바로 열리고, 서비스 워커가 캐시해 한 번 열면 오프라인으로도 동작한다.
- **접근성.** 키보드 방향키로 칸을 옮기고, 버튼마다 상황을 읽어주는 레이블이 붙는다. 모션 감소 설정도 존중한다.

## 모드

- **도전**: 흰색을 맡아 10단계를 푼다. 단계별 목표 수 안에 체크메이트하면 별 3개. 진행 상황은 브라우저에 저장된다.
- **AI 대국**: 8기물 대칭 시작 위치에서 AI와 둔다. 흰색/검정 선택 가능.
- **2인용**: 같은 기기에서 번갈아 둔다. 뒤집기 버튼으로 화면을 바꿀 수 있다.

## 규칙 요약

| 기물 | 이동 |
| --- | --- |
| 왕 | 인접한 한 칸 |
| 퀸 | 직선·대각선 |
| 룩 | 직선 |
| 비숍 | 대각선 |
| 나이트 | L자 |
| 폰 | 앞으로 한 칸(처음엔 두 칸), 대각선 잡기, 마지막 줄에서 승격 |

캐슬링은 4x4 판에서는 쓰지 않는다.

## 개발

빌드 단계 없다. Node 20 이상에서 테스트만 돌리면 된다.

```bash
npm test            # 규칙 엔진, 퍼즐 검증, AI 스모크 테스트
npm run puzzles     # 강제 체크메이트 위치를 새로 탐색 (개발용)
python -m http.server 8000
```

그다음 `http://localhost:8000` 에서 플레이한다. ES 모듈을 쓰므로 `file://` 로 직접 열기보다 로컬 서버를 권장한다.

## 구조

- `src/rules.js` — 순수 규칙 엔진(DOM 의존 없음)
- `src/ai.js` — 미니맥스 AI
- `src/solver.js` — 강제 체크메이트 탐색, 퍼즐 검증과 힌트에 사용
- `src/puzzles.js` — 검증된 10개 스테이지와 대국 시작 위치
- `src/main.js` — 화면과 입력 처리
- `tools/find-puzzles.mjs` — 새 퍼즐 후보 탐색기
- `tests/` — `node:test` 기반 테스트

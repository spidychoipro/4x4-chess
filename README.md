# 4x4 체스

구글 플레이의 [4x4 체스](https://play.google.com/store/apps/details?id=com.westplain.chess)를 보고 만든 웹 버전이다. 4x4 판에 말 8개를 놓고 하는 건 같다. 원작처럼 주사위를 굴려 선공을 정하고, 매 판 말이 새로 놓인다. 광고가 없고, 앙파상이 되고, 상대 레이팅을 고를 수 있다. 원작에 있던 시간제한은 클래식 모드에 넣었다.

바로 가기: https://spidychoipro.github.io/4x4-chess/

## 원작이랑 다른 점

원작은 화면을 터치해 주사위를 멈추고 큰 수가 나온 쪽이 먼저 둔다. 판 위에는 말 8개를 무작위로 놓고, 단계가 오를수록 세로·지그재그 같은 배치가 나온다. 일부 단계에는 시간제한이 있고 친구와 같은 기기에서 둘 수도 있다. 이 버전의 클래식 모드가 그 부분을 맡는다.

나머지는 원작과 다른 쪽으로 갔다.

| | 플레이스토어 앱 | 이 버전 |
| --- | --- | --- |
| 선공 | 주사위로 결정 | 클래식과 2인용은 주사위로 결정, 도전과 AI 대국은 흰색부터 |
| 말 배치 | 단계마다 무작위 | 클래식은 무작위 20단계, 도전은 검증된 고정 판 10개 |
| 시간제한 | 일부 단계에 있음 | 클래식 6단계부터 일부 단계에 있음 |
| 앙파상 | 없음. 플레이스토어 리뷰에도 지적이 있음 | 지원 |
| 상대 | AI와 2인용 | 레이팅 8단계 봇과 2인용 |
| 광고 | 있음 | 없음 |

도전 모드는 원작에 없던 방식이다. 첫 수가 한 가지만 맞는 강제 체크메이트 판을 10개 모았다. 이길 수 있는 판인지 프로그램으로 검증해서 넣었으니 운으로 당첨되는 단계는 없다.

## 모드

- **클래식** — 원작에 가장 가깝다. 주사위로 선공을 정한 뒤 20단계를 시작하고, 새 판마다 말 8개가 다시 놓인다. 6단계부터 배치가 세로·지그재그로 바뀌고 시간제한이 붙는 단계가 생긴다. 단계가 오르면 상대 봇도 강해진다. 이기면 다음 단계가 열린다. 봇 대신 같은 기기에서 2인용으로도 할 수 있다.
- **도전** — 흰색을 맡아 10판을 푼다. 목표 수 안에 체크메이트하면 별 3개. 힌트를 쓰면 별이 하나 줄고, 진행 상황은 브라우저에 저장된다.
- **AI 대국** — 양쪽이 같은 기물을 가진 고정 배치에서 둔다. 흰색·검정 선택 가능.
- **2인용** — 같은 기기에서 번갈아 둔다.

## 봇 레이팅

탐색 깊이, 평가 방식, 실수 확률을 단계마다 다르게 줬다. 공식 FIDE 점수가 아니라 이 게임 안에서의 체감 난이도다.

| 레이팅 | 이름 | 성격 |
| --- | --- | --- |
| 100 | 첫 걸음 | 규칙을 막 배운 사람처럼 가끔 엉뚱한 수를 둠 |
| 300 | 동네 형 | 기물은 잘 잡지만 함정은 잘 못 봄 |
| 600 | 취미 생활 | 한 수 뒤까지 보고, 실수도 종종 함 |
| 1000 | 동아리 | 기물과 위치를 함께 봄 |
| 1500 | 클럽 챔피언 | 눈앞의 실수를 저지르지 않음 |
| 2000 | 국가대표 | 두 수 뒤까지 계산함 |
| 2400 | 그랜드마스터 | 세 수 뒤까지 읽음 |
| 2800 | 최정상급 | 가장 긴 계산. 한 수만 어긋나도 끝남 |

## 규칙

기물의 움직임은 일반 체스와 같다. 왕은 인접한 한 칸, 퀸은 직선과 대각선, 룩은 직선, 비숍은 대각선, 나이트는 L자, 폰은 앞으로 한 칸과 대각선 잡기다. 폰은 처음에 두 칸 전진할 수 있고 그 직후에는 앙파상으로 잡힌다. 마지막 줄에 닿으면 퀸·룩·비숍·나이트 중 하나로 승격한다. 두 칸 전진으로 승격할 때도 같다.

캐슬링은 판이 작아 쓰지 않는다. 클래식과 2인용은 주사위를 터치해 멈추고 큰 수가 나온 쪽이 먼저 둔다. 같은 수가 나오면 다시 굴린다. 체크메이트와 스테일메이트를 구분하고, 기물 부족·50수·같은 위치 3회는 무승부다.

## 개발

빌드 단계는 없다. Node 20 이상에서 테스트를 돌린 뒤 로컬 서버를 띄우면 된다.

```bash
npm test
npm run puzzles    # 강제 체크메이트 판을 새로 찾을 때
python -m http.server 8000
```

ES 모듈을 쓰므로 `file://` 로 열기보다 `http://localhost:8000` 에서 보는 게 낫다.

- `src/rules.js` — 규칙 엔진. DOM에 의존하지 않는다.
- `src/classic.js` — 랜덤 8기물 배치 생성.
- `src/dice.js` — 주사위 값과 선공 판정.
- `src/ai.js` — 봇.
- `src/solver.js` — 강제 체크메이트 탐색. 퍼즐 검증과 힌트에 쓴다.
- `src/puzzles.js` — 도전 코스 10판과 AI 대국 시작 배치.
- `src/main.js` — 화면과 입력.
- `tests/` — `node:test` 테스트.

GitHub Pages에서 main 브랜치를 그대로 배포한다. 주소는 https://spidychoipro.github.io/4x4-chess/ 이다.
